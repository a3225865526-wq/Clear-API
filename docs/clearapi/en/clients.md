# Client setup

OpenCode, Cherry Studio, and Chatbox can be configured as OpenAI-compatible clients with `https://www.clear999.com/v1`, a Clear API key, and a model ID returned by `/v1/models`. If a client appends `/v1`, use the host URL and configure the path separately.

Codex CLI and Claude Code are not provider-verified. The existence of Responses and Anthropic source routes does not prove full CLI compatibility; tool calls, streaming events, authentication, and upstream behaviour remain unverified.
