# 模型、额度与错误排查

额度依据账号当前模型价格及上游 usage 结算。普通文本通常涉及输入和输出 token；不同模型还可能涉及缓存、多模态或其他计费维度。价格、倍率和余额以面板及运营方公告为准，本页不维护可能过期的价格表。

失败排查：先 `GET /v1/models`；确认 URL 仅有一个 `/v1`；检查 Bearer Key 与 JSON Content-Type；以最小纯文本请求重试；保存状态码、结构化错误和 request ID。不要在工单里粘贴 API Key、密码或敏感 prompt。

一般状态码：`400` 请求错误，`401` 凭据错误，`403` 权限拒绝，`404` 路径或模型不存在，`429` 限流/额度限制，`5xx` 网关或上游错误。Anthropic 形式错误使用外层 `type: error` 与 `error` 字段；其他接口常使用 `error` 对象。客户端应优先依据状态码和结构化字段判断。
